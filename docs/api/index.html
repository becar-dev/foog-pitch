API Access

FOOG REST API v1

Ilova va backend o‘rtasidagi kontrakt bitta manbadan — @foog/contracts (zod sxemalari). Quyida asosiy endpointlar tuzilmasi.

Ommaviy API hali ochilmagan: production deploy (TASK-092) rejada. Bu sahifada kalit, token yoki server manzili yo‘q. Hamkorlik uchun kirish — jamoa orqali so‘rov bilan.

Umumiy qoidalar

  • Base: /api/v1 · JSON, UTF-8
  • Auth: Authorization: Bearer <accessToken>
  • Vaqt — ISO 8601 UTC, ko‘rsatish Asia/Tashkent bo‘yicha
  • Pul — so‘mda butun son
  • Sahifalash: ?cursor=&limit= → { items, nextCursor }
{ "success": true,  "data": { ... } }
{ "success": false, "error": { "code": "SLOT_TAKEN", "message": "..." } }

Asosiy xato kodlari: VALIDATION_ERROR 400 · UNAUTHORIZED 401 · FORBIDDEN 403 · NOT_FOUND 404 · SLOT_TAKEN 409 · INVALID_STATE 409 · RATE_LIMITED 429
