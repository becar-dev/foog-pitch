Demo tavsifi

Nimani ko‘rsatamiz

  • Kirish: “Telegram orqali kirish” → bot tasdig‘i → hisob yaratiladi. Parol yo‘q.
  • Rol: futbolchi yoki stadion egasi; bitta akkaunt ikkalasiga ham ega bo‘la oladi.
  • Onboarding: pozitsiya, kuchli oyoq, daraja, shahar.
  • Bron: stadion → sana → bo‘sh slot → ushlab turish (10 daq) → so‘rov → egasi tasdig‘i.
  • Ishonchlilik: bir slotga ikki bron — imkonsiz (baza darajasida himoya).
  • Jarayon: AI agentlar bilan ticket → review → merge sikli.

Demo’da nima haqiqiy

/prototype — haqiqiy FOOG ilova kodi, web eksport, mock rejim: Telegram kirish simulyatsiya qilinadi (6 soniyadan so‘ng avtomatik tasdiq). Backend ulanmagan — ma’lumot bloklari “Yuklab bo‘lmadi” holatini ko‘rsatadi.
/booking — bron oqimining statik interaktiv konsepti (FOOG dizayni asosida). Ilovadagi stadion va bron ekranlari hali ishlab chiqilmoqda (TASK-073, 074).
