# FOOG — Pitch Day 3.0 sayti

Statik sayt (`docs/`), GitHub Pages orqali joylanadi.

- `/` — pitch sahifasi
- `/demo/` — demo video, tavsif, ssenariy
- `/prototype/` — FOOG Expo ilovasining web eksporti (mock rejim, backend ulanmagan)
- `/booking/` — bron oqimining statik interaktiv konsepti
- `/api/` — API tuzilmasi (maxfiy ma’lumotsiz)

Lokal ko‘rish: `node serve.mjs docs` → http://localhost:4321/foog-pitch/
